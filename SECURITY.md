# Security

## Data handling

Credential Calendar Maker processes the selected CSV in the current browser
tab. It has no analytics, account, backend, network request, storage database,
provider connection, or credential field. Generated calendar content exists in
browser memory until the page is closed or another file is processed.

Use synthetic data in bug reports. Do not attach real employee names, email
addresses, identifiers, credentials, or expiration dates.

## Supported version

Security fixes are applied to the latest release on `main`.

## Reporting

Please use GitHub’s private vulnerability-reporting feature when available.
Include a minimal synthetic reproduction, affected version, and expected
impact. Do not open a public issue containing sensitive workforce data.
